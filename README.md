This is a simple approximation of where things are in the sky using JPL's "Keplerian Elements for Approximate Positions of the Major
Planets". [Citation here](https://ssd.jpl.nasa.gov/txt/aprx_pos_planets.pdf)]

I think it is fun and worth sharing.

```
## Dependencies
- libncursesw (wide-character ncurses)
- libm
- libtinfo

## Build
cc sky.c -o sky -lncursesw -lm

```

Take care of each other.
